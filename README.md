# CalShot

把屏幕截图里的活动安排，识别为可修改并保存的 Apple / iCloud 日历日程。

**当前版本：0.1.13**

**目前支持的API： DeepSeek 官方 API**

**iCloud 安装链接：**

屏幕截图 → 模型识别 → 系统“新建日程”编辑页 → 修改并保存。

## 功能

- 识别截图中的标题、时间、地点及活动说明，最多提取 10 条日程。
- 最多配置 5 个候选日历，自动读取所选日历名称。
- 按事件内容预选已配置的日历；无法分类时使用第一个具体日历。
- 没有明确要求时，默认提前 30 分钟提醒。
- 详细信息保留来源、编辑页生成时间、原文及实际活动备注。

## 首次配置

准备好 iPhone“快捷指令”App、DeepSeek API Key，以及至少一个可添加日程的日历。API Key 可在[DeepSeek 开放平台](https://platform.deepseek.com/)获取。

1. 在 iPhone 上打开本页的 iCloud 安装链接，进入快捷指令配置页面。
2. 在 API Key 设置项中填入你的 **DeepSeek API Key**，替换 `PASTE_API_KEY_HERE`。
3. 当前安装版最多配置 **5 个日历**。每项点击“所有日历”后选择一个具体日历，至少配置一个；不用的位置保留“所有日历”。名称自动读取，无需手输，第一个具体日历为默认。
4. 点击“添加快捷指令”，在列表中保留一份名称为 **CalShot** 的当前版本。

如果 iOS 27 的安装页面没有关闭，已有反馈可通过“跳过设置”返回列表，所选日历仍能保留；原因尚未确认。提示缺少配置时，在详情的“设置 → 自定义快捷指令”中重新填写。升级时导入新版、重新配置，并将轻点背面等入口改为新版 CalShot。

## 截图使用

1. 在 iPhone“设置 → 辅助功能 → 触控 → 轻点背面 → 轻点两下”中选择 CalShot。[Apple 设置说明](https://support.apple.com/zh-cn/111772)
2. 保持手机解锁，在屏幕上显示活动安排，轻点两下背面。
3. 等待系统日历编辑页出现，修改或核对内容，点击“添加”或右上角勾保存。多条日程逐条处理。

例如截图中写着“10月13号下午6:00和朋友吃饭”，设备当前年份为2026时，预期填入10月13日18:00–19:00，默认提醒时刻为17:30。

## 使用须知

缺年份采用设备当前年份；开始日期或时刻不完整时只补缺失部分；非全天事件缺结束时间或结束不晚于开始时预填开始后一小时；全天事件缺结束边界按一天处理；缺标题预填“待确认日程”。

识别可能有误，保存前请检查内容、目标日历和提醒。提前提醒按具体时刻设置，修改开始时间后也应检查提醒。当前版本的计算提醒、修改保存和通知触发仍待完整真机验证。

当前预设使用 DeepSeek API，暂不支持在安装页切换服务、模型或思考强度。截图、设备当前时间及候选日历名称会发送到 DeepSeek，并使用你的 API 额度；已有日程不会被查询或上传。API Key 保存在手机快捷指令中，请勿公开填写密钥后的快捷指令。

当前使用方式为屏幕截图。等待时间有时波动，原因尚未确定。详细信息里的“添加时间”是编辑页生成时间。
